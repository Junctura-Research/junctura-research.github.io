# junctura-research.github.io

Source of [juncturaresearch.com](https://juncturaresearch.com), the public site of Junctura Research. It is a [Quarto](https://quarto.org) website, built and published to GitHub Pages by GitHub Actions on every push to `main`.

Drafts are written and validated in the private research repository. Only documents the reviewer has approved are copied here.

## Layout

| Path | What it is |
| --- | --- |
| `index.qmd` | Home page and the list of publications (built automatically from `research/`) |
| `about.qmd` | How the research is produced and directed |
| `corrections.qmd` | Every published error, the date found, and the fix |
| `_disclaimer.md` | The disclaimer text, kept in one place. Used by the Disclaimer page and appended to the end of every PDF. Change it only with the attorney's approval |
| `disclaimer.qmd` | The Disclaimer page, linked from the footer of every page |
| `_registry.yml` | The list of Intersections and Junctions: titles, descriptions, images, last-reviewed dates. The Intersection pages and the home-page list are built from it |
| `_corrections.yml` | Every correction, entered once; shown on the Corrections page and on the document's Intersection page |
| `intersections/<id>.qmd` | Generated by `scripts/build_pages.py`; not committed. One page per intersection with a published document |
| `images/intersections/` | Web versions of the intersection images (banner, social preview, thumbnail), made by `scripts/make_images.py`. The licensed originals stay in the private research repository |
| `research/<slug>.qmd` | One published document. Renders to `/research/<slug>.html` and `/research/<slug>.pdf` |
| `research/_metadata.yml` | Settings for every document: HTML and PDF output, the type and as-of line |
| `data/<slug>/` | The document's frozen data appendix, served as plain files at `/data/<slug>/` |
| `filters/doc-meta.lua` | Adds "Research Note · Evidence as of …" and the PDF link to each document; appends the full disclaimer to every PDF; adds the Google Scholar PDF tag |
| `scripts/data_index.py` | Runs after each render; writes a file-listing page into every folder under `_site/data/` so folder links work |
| `scripts/check_links.py` | Fails the build if any internal link (including `https://juncturaresearch.com/...` links) points to a missing file |
| `_quarto.yml` | Site settings: navigation, footer (disclaimer link and review statement), search, sitemap |
| `.github/workflows/publish.yml` | Build on every pull request; build and publish on `main` |

## Publishing an approved document

1. Copy the approved `.qmd` from the research repository to `research/<slug>.qmd`, using the folder name as the slug (e.g. `papers/ai-drug-candidates-2026-11/note.qmd` becomes `research/ai-drug-candidates-2026-11.qmd`).
2. Copy its `data/` folder to `data/<slug>/`. Do not add or rename files inside it; it is frozen.
3. Check the front matter: `title`, `subtitle`, `description`, `date`, `as-of`, `document-type` (`research-note`, `intersection-report` or `report-update`), `junction`, `google-scholar: true`. The `junction` must be listed in `_registry.yml`; for a new Junction, add it there (title, intersection, sub-tech, description, last-reviewed date). For a new intersection's first document, add its description.
4. Open a pull request. The build renders the site, writes the data folder indexes and checks every internal link. Download the `site-preview` artifact from the run to look at it.
5. Merge. The site updates within a few minutes.

A Report Update edits the report's own file in place: new `as-of` date and a dated changelog entry in the report. A correction also gets an entry in `_corrections.yml`. After a periodic review, update the Junction's `last-reviewed` date in `_registry.yml`.

## Building locally

Install Quarto 1.8 and PyYAML, then run `python3 scripts/build_pages.py` once (it writes the Intersection pages, which Quarto needs before it starts), then `quarto preview` (live) or `quarto render` followed by `python3 scripts/check_links.py _site`. The PDF uses Typst, which ships with Quarto; the first render downloads one Typst package.

## One-time settings

- Settings → Pages → Build and deployment → Source: **GitHub Actions**.
- Settings → Pages → Custom domain: `juncturaresearch.com`; tick **Enforce HTTPS** once the certificate is issued.
